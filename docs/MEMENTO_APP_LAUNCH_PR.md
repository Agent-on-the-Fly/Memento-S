# Memento-S App Launch: A Self-Improving Agent on Your Desktop

We are officially launching the Memento-S desktop app. Users no longer need to configure a Python environment or start the project from source. Download the installer for Windows or macOS, open the app, and start using Memento-S directly.

Memento-S is not just another chat assistant that calls tools. It is designed to help agents keep learning from real tasks. It organizes capabilities as searchable, executable, and reusable skills. When a task fails or performance is unstable, the system can reflect on the execution process, improve existing skills, and create new ones so the skill library grows through use.

## Why We Built the App

Until now, Memento-S has mainly served developers and researchers. You could run the framework from source, debug the skill system, and study how agents learn at deployment time. To make Memento-S useful to more people, the desktop app is the natural next step.

With the app release, users can try Memento-S with a much lower setup cost:

- Desktop chat and task execution
- Local file, document, spreadsheet, and web skills
- A skill system designed to keep expanding
- Multi-step execution and reflection for real tasks
- Continuous product updates through the app

Memento-S is no longer only an open-source project that can be deployed locally. It is now also an agent product that users can install, try, and keep using as it evolves.
