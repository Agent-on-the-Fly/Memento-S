# Memento-S App 正式发布：让会学习的 Agent 走到每个人桌面上

我们正式发布了 Memento-S 桌面 App。现在，用户无需配置 Python 环境、无需从源码启动项目，只要下载安装包，就可以在 Windows 或 macOS 上直接体验 Memento-S。

Memento-S 的目标不是再做一个只会调用工具的聊天助手，而是让 Agent 在真实任务中持续学习。它会把常用能力组织成可检索、可执行、可沉淀的 Skills；当任务失败或效果不稳定时，系统能够基于执行过程反思问题，优化已有技能，甚至创建新的技能，让能力库随着使用不断成长。

## 为什么发布 App

过去，Memento-S 更多面向开发者和研究者。大家可以通过源码运行框架、调试技能系统、研究 Agent 如何在部署期学习。但如果想让更多人真正用起来，桌面端是更自然的入口。

这次 App 发布后，普通用户可以更低门槛地体验：

- 桌面端对话与任务执行
- 本地文件、文档、表格、网页等多种技能调用
- 可持续扩展的 Skill 系统
- 面向真实任务的多步执行与反思
- 后续版本的持续更新

也就是说，Memento-S 不再只是一个可以本地部署的开源项目，而是一个可以直接试用、持续迭代的 Agent 产品。
